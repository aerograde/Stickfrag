# Taste
- Prioritizes raw performance ("must be VERY fast") but refuses optimizations that reduce visual quality — treat visual fidelity as a hard constraint, not a tunable. Confidence: 0.7
- Expects any added effect or feature to be frame-rate-neutral: if it measurably costs FPS, gate or remove it rather than accept the trade ("make motion blur not affect FPS at all"). Confidence: 0.7
- Repeatedly asks for extreme lightness in resource terms ("as light as a notepad", "make it even lighter to save ram and resources") and treats lean footprint (RAM, parse cost, bundle size) as a continuing first-class goal, not a one-time cleanup. Confidence: 0.8
- Means runtime resource consumption when asking for "lighter" — CPU, GPU and RAM. Stripping assets or files is not what he wants; when the agent started cutting images/assets he corrected it sharply ("No. Keep all of the image files and such. By lighter, i mean less CPU, GPU, and RAM usage"). Optimize measured frame time, draws and heap, not download size. Confidence: 0.75
- Wants deliverables to be fully standalone single files: everything inlined so the artifact opens and runs on its own (local `file://`, no external requests, no sibling assets). Confidence: 0.65
- Wants design decisions reviewed by them before implementation: asks for a list/plan to be run by them first rather than having large features built straight away. Confidence: 0.6
- Wants the real existing UI/assets ported over AND its behaviour reproduced, not a hand-rolled approximation or a reduced subset: vendor the original verbatim and trim from that ("No. This looks quite frankly, awful. I have here what might be the homescreen"), and when a flow is missing or stubbed he expects parity with the live site, e.g. "It must be exactly like stickfrag.com, where i can also select gamemodes". Confidence: 0.7
- Rejects "not possible without the original source/missing resource" as an answer — expects the agent to exhaust what is available (archives, deobfuscation, reconstruction) and prove the limit empirically before declaring something unrecoverable or blocked. Confidence: 0.6
